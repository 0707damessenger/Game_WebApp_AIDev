# 个人网站设计文档

## 核心目的

搭建一个个人网站空模板，用于后续填写个人介绍、项目与外部链接。当前阶段先复刻参考站的极简个人主页气质，不填入真实个人内容。

## 页面结构

网站采用单页切换结构，顶部导航包含：首页、项目、链接。

首页用于展示头像占位、姓名占位、身份短句占位和个人简介段落占位。

项目页用于展示代表作、参与项目列表和开源项目列表。页面顶部横向展示被标记为代表作的项目；其下的纵向项目条目支持展开详情。项目条目支持插入本地展示图片，未配置图片时继续显示几何占位。

链接页以“我的主页”和“朋友们”两类名片内容为主体。联系方式放在页面标题下方，作为小图标与文字组成的轻量信息行，不单独形成内容分组。空的内容区域不显示。名片支持插入本地展示图片，未配置图片时继续显示几何占位。

写真页不纳入当前版本。

## 视觉风格

整体采用极简白底、大留白、轻字体和克制的浅色渐变。不同页签通过淡色主题区分：主页偏清爽蓝色，项目偏绿色，链接偏黄色。

头像、页签图案、项目图标和链接头像默认使用纯色几何占位。头像、页签、项目和链接允许通过本地 PNG 资源替换，图片加载失败时回退为几何占位。

## 图片资源规划

图片资源按使用范围分为站点头像、页签图案、项目展示图和链接展示图四类。项目与链接图片继续按页面中的内容分组，保证后续新增内容时可以直接放入对应分类，不需要调整页面结构。

所有图片均为可选资源。配置图片后使用图片展示，未配置时保留原有占位图形。项目详情支持配置多张图片，但同一时刻只展示一张；每张图片可配置对应的文字说明，切换图片时同步切换说明。图片只承担展示作用，不改变导航和内容分组规则。

## 首页水波分隔

首页个人名片区与简介正文之间使用更接近真实水面的平缓波纹分隔。波面以蓝色区域承接下方内容，波形保持流畅且持续轻微变化，不承载文字或交互内容；用户开启减少动态效果设置时，水波保持静止。

## UI 布局

顶部导航始终位于页面顶部，桌面端显示文字导航，移动端压缩为更紧凑的导航形式。

首页采用居中个人名片区和下方简介文本区。项目页顶部先展示代表作横排，下方使用纵向项目列表承载可展开详情；详情采用图片浏览区与文字描述结合的布局，移动端改为上下排列。链接页以“我的主页”和“朋友们”为主要分组，主页名片使用简洁列表或低密度网格；联系方式紧跟页面标题，以连续的图标文字行呈现，降低视觉层级。

## 交互逻辑

点击顶部导航时在同一页面内切换对应内容，不刷新页面。

首页简介支持将指定文字设置为页签链接。点击“看看项目”时，在同一页面内切换到“项目”页签，不刷新页面。

通过顶部导航切换页签，或通过首页简介链接跳转页签时，页面滚动位置回到顶部，避免保留上一页签的浏览位置。

当前页签需要有明显但轻量的高亮状态。页面切换时保持轻微过渡，避免强动画。

头像、页签图案、项目展示图和链接展示图均通过本地资源配置替换，未配置或加载失败时显示对应几何占位。

项目卡片与链接页卡片的占位链接当前不跳转，只用于展示未来内容位置；首页简介中的“看看项目”链接切换到“项目”页签。

纵向项目条目的图标、标题和简介区域均可点击展开或收起详细内容；同一时间只展开一个项目，展开另一个项目时自动收起原项目。详细内容包括项目文字描述和图片浏览区；配置多张图片时通过左右控制切换，图片顺序循环，界面显示当前图片位置与图片总数，并在有配置时显示当前图片说明。项目可配置外部目标网址，配置后在展开详情中显示“前往”入口并在新标签页打开；未配置网址时不显示该入口。

代表作横排中的项目交互区域用于快速跳转到对应的纵向项目，并直接展开该项目详情；代表作与纵向项目使用同一项目内容，不重复维护详情。

项目展开后，项目的图标、标题和简介区域在页面向下滚动时固定在页签导航下方；直到该项目的详细内容完全离开可视区域后解除固定。点击固定的交互区域可以收起项目，收起时保留当前滚动位置。

我的主页与朋友们的名片支持跳转到外部主页，外部主页默认在新标签页打开。联系方式按配置的联系方式类型执行对应行为，例如邮箱使用邮件链接；缺少跳转地址时仅展示内容，不执行跳转。
