# 个人网站设计文档

## 核心目的

搭建一个个人网站空模板，用于后续填写个人介绍、项目与外部链接。当前阶段先复刻参考站的极简个人主页气质，不填入真实个人内容。

## 页面结构

网站采用单页切换结构，顶部导航包含：首页、项目、链接。

首页用于展示头像占位、姓名占位、身份短句占位和个人简介段落占位。

项目页用于展示个人项目入口、参与项目列表和开源项目列表。项目卡片支持插入本地展示图片，未配置图片时继续显示几何占位。

链接页用于展示友链或常用链接分组。链接卡片支持插入本地展示图片，未配置图片时继续显示几何占位。

写真页不纳入当前版本。

## 视觉风格

整体采用极简白底、大留白、轻字体和克制的浅色渐变。不同页签通过淡色主题区分：主页偏清爽蓝色，项目偏绿色，链接偏黄色。

头像、页签图案、项目图标和链接头像默认使用纯色几何占位。头像、页签、项目和链接允许通过本地 PNG 资源替换，图片加载失败时回退为几何占位。

## 图片资源规划

图片资源按使用范围分为站点头像、页签图案、项目展示图和链接展示图四类。项目与链接图片继续按页面中的内容分组，保证后续新增内容时可以直接放入对应分类，不需要调整页面结构。

所有图片均为可选资源。配置图片后使用图片展示，未配置时保留原有占位图形；图片只承担展示作用，不改变导航、内容分组和卡片交互规则。

## 首页水波分隔

首页个人名片区与简介正文之间使用更接近真实水面的平缓波纹分隔。波面以蓝色区域承接下方内容，波形保持流畅且持续轻微变化，不承载文字或交互内容；用户开启减少动态效果设置时，水波保持静止。

## UI 布局

顶部导航始终位于页面顶部，桌面端显示文字导航，移动端压缩为更紧凑的导航形式。

首页采用居中个人名片区和下方简介文本区。其余页面采用内容容器居中排列，项目以网格和列表结合呈现，链接以横向卡片流呈现。

## 交互逻辑

点击顶部导航时在同一页面内切换对应内容，不刷新页面。

首页简介支持将指定文字设置为页签链接。点击“看看项目”时，在同一页面内切换到“项目”页签，不刷新页面。

通过顶部导航切换页签，或通过首页简介链接跳转页签时，页面滚动位置回到顶部，避免保留上一页签的浏览位置。

当前页签需要有明显但轻量的高亮状态。页面切换时保持轻微过渡，避免强动画。

头像、页签图案、项目展示图和链接展示图均通过本地资源配置替换，未配置或加载失败时显示对应几何占位。

项目卡片与链接页卡片的占位链接当前不跳转，只用于展示未来内容位置；首页简介中的“看看项目”链接切换到“项目”页签。
