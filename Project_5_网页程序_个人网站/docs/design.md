# 个人网站设计文档

## 核心目的

搭建一个个人网站空模板，用于后续填写个人介绍、项目、笔记与外部链接。当前阶段先复刻参考站的极简个人主页气质，不填入真实个人内容。

## 页面结构

网站采用单页切换结构，顶部导航包含：首页、项目、笔记、链接。

首页用于展示头像占位、姓名占位、身份短句占位和个人简介段落占位。

项目页用于展示个人项目入口、参与项目列表和开源项目列表。当前全部以空内容占位呈现。

笔记页用于展示笔记分类筛选和笔记列表。当前保留分类与列表结构，内容为空占位。

链接页用于展示友链或常用链接分组。当前保留分组与链接卡片结构，内容为空占位。

写真页不纳入当前版本。

## 视觉风格

整体采用极简白底、大留白、轻字体和克制的浅色渐变。不同页签通过淡色主题区分：主页偏清爽蓝色，项目偏暖橙色，笔记偏绿色，链接偏灰蓝色。

头像、项目图标、笔记标记和链接头像均使用纯色几何占位，不依赖美术资源。

## UI 布局

顶部导航始终位于页面顶部，桌面端显示文字导航，移动端压缩为更紧凑的导航形式。

首页采用居中个人名片区和下方简介文本区。其余页面采用内容容器居中排列，项目以网格和列表结合呈现，笔记以纵向文章列表呈现，链接以横向卡片流呈现。

## 交互逻辑

点击顶部导航时在同一页面内切换对应内容，不刷新页面。

当前页签需要有明显但轻量的高亮状态。页面切换时保持轻微过渡，避免强动画。

笔记分类保留筛选入口，当前只作为模板结构展示。

所有占位链接当前不跳转，只用于展示未来内容位置。
