# 桌面餐车 - 探索文档

> 本文档存放尚未确认的候选方案与暂不纳入内容。与 [design.md](design.md) 冲突时，以 `design.md` 为准；候选方向确认后，应先写入 `design.md`，再从本文档移除。

## 1. 美术制作方式

整体方向已确认为二维像素卡通与手绘帧动画，但具体生产方式尚未锁定。后续需要用视觉样稿比较：

- 低分辨率像素画直接逐帧绘制。
- 普通分辨率手绘卡通，再统一处理为像素质感。
- 手绘卡通原画，由运行时显示效果形成像素风格。

评估重点包括画面美感、缩放清晰度、动画工作量、餐车改装兼容性和长期内容产能。

## 2. 未采用的完整主结构

项目已确认采用“专注优先的双层循环”，正式结论见 [design.md](design.md)。以下两种方案不作为完整主结构，但各自的部分特征已经被主结构吸收：

- **观赏优先的旅行明信片**：不独立作为主结构，因为容易让经济循环退化为解锁画面的附属条件；其“可见成长”原则已被采用。
- **经营优先的增量餐车**：不独立作为主结构，因为容易诱导频繁检查收益；其“新闻驱动短期规划”原则已被采用。

完整比较与依据见 [设计讨论记录](plans/桌面餐车-design.md)。

## 3. 待探索问题

- 如何保留新闻的规划价值，同时降低错过新闻带来的焦虑。
- 如何让吆喝值奖励真实工作输入，而不鼓励刷按键或造成职业差异。
- 如何控制宝箱错过压力，使其成为自然取舍而非工作阶段的催促。
- 如何把线性升级持续转化为餐车和世界的可见变化。
- 如何限制菜谱、顾客、新闻与地点的组合内容成本。
