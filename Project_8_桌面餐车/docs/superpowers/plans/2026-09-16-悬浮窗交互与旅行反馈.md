# 悬浮窗交互与旅行反馈 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现餐车主体拖动、向上菜单、轻量番茄钟开关、旅行道路收集反馈、单次阶段气泡与休息阶段提前开始。

**Architecture:** 番茄钟规则继续由独立状态机负责；旅行状态机新增道路物件队列，并在物件完成收集阶段时结算库存。界面层只渲染状态并处理指针拖动，Toast 是否首次进入由应用层记录事件编号，避免计时刷新重复动画。

**Tech Stack:** 原生 HTML、CSS、JavaScript ES modules、Node test runner、Playwright。
