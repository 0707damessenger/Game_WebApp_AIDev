# Spellatoon 自由预览恢复计划

**目标：** 恢复项目 6 的任意空格悬浮、锁定和假设连锁/吞噬预览，并保持项目 7 的高权重计分。

**边界：** 本模块只读公共棋盘。它不提交网络动作、不读取对手手牌、不改变真实状态，也不涉及倒计时或断线恢复。

## 任务 1：规则层预览 API

- [ ] 在 `prototype/tests/rules.test.mjs` 先写测试：空格可找出同横纵且位于连锁范围内的卡牌；已占用格不可锁定；以锁定空格和目标牌数字模拟时返回加权路径分数且不改变原棋盘。
- [ ] 运行规则测试，确认因 `getPreviewTargets`、`lockPreviewCell` 和 `simulatePreview` 缺失而失败。
- [ ] 在 `prototype/js/rules.mjs` 实现三个纯函数。目标筛选仅基于横纵距离；锁定仅接受棋盘内空格；模拟使用目标牌数值和当前玩家颜色在克隆状态中调用既有连锁/吞噬结算。
- [ ] 重跑规则测试，确认新行为和既有规则均通过。

## 任务 2：浏览器状态与可视化

- [ ] 在 `prototype/tests/ui-contract.test.mjs` 先写浏览器契约：未选牌时悬浮空格会高亮关联牌；点击空格后保留锁定状态；悬浮关联牌会显示连锁或吞噬与预计得分；再点锁定格会取消。
- [ ] 运行 UI 契约，确认当前实现无法满足新选择器与文本断言。
- [ ] 在 `prototype/js/app.mjs` 增加自由预览状态及指针/点击处理；在 `prototype/js/render.mjs` 增加关联目标、锁定格、假设路径的渲染与说明；在 `prototype/css/styles.css` 给予三种状态稳定且不改变格子尺寸的视觉区分。
- [ ] 运行完整测试、浏览器交互脚本与截图检查，确认真实棋盘不变、自由预览可取消且已选牌时回到行动预览。
