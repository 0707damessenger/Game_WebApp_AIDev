# Spellatoon 优化版探索与风险评估

## 评估范围

本次评估基于原版 Spellatoon 规则、现有网页原型以及少量单人双端完整对局。原项目保持不变，优化结论仅用于独立的新项目。

当前体验目标已确认为：以领地争夺为主，以连锁构筑和心理博弈为辅。首轮只验证生命压力、中央高权重区域、行动点经济与更快补牌，不引入阶段变化或随机事件。

## 已有观察与证据强度

| 观察 | 当前证据 | 判断 |
|---|---|---|
| 对局后段拖沓 | 少量自测中不明显 | 暂不作为主要矛盾；生命机制仍可能自然缩短部分对局 |
| 回合之间缺少变化 | 少量自测中明显 | 高优先级体验风险，但样本不足以判断具体成因占比 |
| 主动部署容易给对手反制窗口 | 少量自测中明显 | 高优先级结构风险，主要来自公开部署信息与对手的回应权 |
| 地图缺少特点和共同争夺目标 | 少量自测中明显 | 高优先级地图风险 |
| 后手存在稳定胜率优势 | 尚无足够对局样本 | 只能确认存在反应者优势风险，不能得出胜率结论 |

## 核心问题诊断

### 主动部署的可靠收益不足

原版普通部署只立即染一格，主要分数来自之后形成连锁或吞噬。部署者先公开数字与位置，对手随后能利用完整公共信息寻找吞噬机会，因此“先暴露、后被针对”可能压过单格收益。

生命结算把当前领地优势转换为回合末的即时收益，使主动部署即使随后成为反制目标，也已经对当回合结果产生价值。该调整解决的是主动方收益时机，不保证自动解决先后手公平。

### 地图没有空间优先级

原版普通地块价值相同，双方没有天然理由在同一区域持续交锋。中央高权重区域同时影响生命压力和路径得分，能用一条规则制造移动、占领、布置同数字卡牌和反制的共同热点。

### 回合节奏缺少局势转折

生命差会让每次回合结束都产生可见后果，中央归属变化也会放大领地差，因此首轮不额外增加固定中盘变化。若测试后回合仍然平缓，再单独研究阶段变化，避免一次修改过多导致无法判断因果。

### 行动结构缺少周转空间

原版每回合分别限制一次移动和一次部署，玩家无法把未使用的行动能力带到下一回合，也不能用重复动作表达策略。行动点将两类动作统一到同一资源中，并允许保留到后续回合；手牌库存则限制连续爆发。

## 已选方案

### 领地压力方案

领地差在每个玩家回合结束后立即转化为生命损失。选择即时结算，是为了让主动占地在对手回应前获得一次确定收益，并直接对冲“先公开部署信息”的成本。

暂不加入伤害上限、缓冲区或衰减。若测试出现明显滚雪球，再根据伤害曲线定位是否需要保护，而不是在没有数据时预先增加规则。

### 中央高权重区域

中央固定区域同时提高领地面积权重与路径计分权重。它不提供额外能力，避免引入新的资源体系；同一权重概念服务两种既有结算，符合用少量规则产生多重策略交互的目标。

### 可储存行动点

移动和部署共享行动点，并允许在上限内跨回合保留。玩家可以选择稳定行动，也可以减少当前投入，为后续连续移动、连续部署或混合爆发保留空间。

### 单机双人测试入口

沿用原版正在采用的交接方式：开始菜单进入单机双人，对局与回合切换时遮住手牌，下一位玩家确认后才显示私有信息并开始计时。该模式只改变设备与交接方式，不改变玩法规则。

## 风险清单

| 优先级 | 风险 | 形成原因 | 首轮验证信号 | 可能的后续处理 |
|---|---|---|---|---|
| 极高 | 先手滚雪球 | 先手先占地并先触发生命结算，领先领地可能在多个回合重复造成伤害 | 先手频繁在对手建立有效反制前结束对局 | 调整结算时机、初始公平补偿或伤害曲线，具体方案待数据决定 |
| 极高 | 中央成为唯一正确目标 | 中央同时强化面积伤害和效果分数 | 双方开局路线高度固定，边缘部署几乎不出现 | 降低中央权重、改变区域形状或仅保留一种加权收益 |
| 高 | 爆发回合强化反应者优势 | 玩家可存储资源，在看到对手部署后连续移动和部署反打 | 大部分高收益行动都由后行动方完成，主动部署仍被回避 | 调整行动点恢复、上限或公开信息，但不预设具体数值 |
| 高 | 生命与分数目标割裂 | 领地决定生命，连锁与吞噬决定超时胜负 | 玩家为保命与为得分采取互不相干的两套策略 | 观察双目标是否形成取舍；若形成无关赛道，再统一或建立转换关系 |
| 高 | 回合上限仍显拖沓 | 若面积长期接近，生命机制可能很少缩短比赛 | 多局都接近回合上限且中后段重复 | 先调整生命与伤害节奏，再评估回合上限，不直接增加阶段规则 |
| 中 | 手牌上限削弱补牌感 | 手牌经常满时，多张补牌会被截断 | 回合开始频繁显示少补或不补，玩家认为补牌规则失效 | 根据手牌曲线再调整补牌或上限；首轮保持当前上限 |
| 中 | 连续部署受占位限制 | 部署只能发生在角色所在空格，部署后该格被卡牌占据 | 玩家以为能连续部署，但必须先移动才能再次部署 | 通过合法目标提示解释，不改变规则 |
| 中 | 单机交接增加测试耗时 | 每回合都需要人工确认交接 | 快速规则测试被遮罩流程明显拖慢 | 保留正式交接模式，后续可增设仅供开发的公开手牌测试开关 |

## 第一轮测试记录要求

每局至少记录：先手方、胜负方式、结束时回合进度、双方剩余生命与分数、每回合加权面积差、中央区域归属、行动点使用量、补牌被上限截断次数，以及主动部署后是否在对手下一回合遭到吞噬。

首轮不要只记录胜率。样本较少时，优先观察以下行为：

- 玩家是否主动部署，还是继续等待对手先暴露数字。
- 中央区域是否带来多条可选路线，而不是形成固定开局。
- 三行动爆发是否稀有且有准备过程，还是成为每轮标准答案。
- 生命压力是否制造紧张与逆转，还是让落后方很早失去有效选择。
- 分数决胜是否只是一种兜底，还是与生命胜利产生冲突。

## 暂不采用的方向

- 固定中盘变化：首轮不加入。先确认生命与中央热点是否已经提供足够节奏变化。
- 随机地图事件或周期资源：会同时增加随机性和学习成本，不利于定位当前结构问题。
- 面积伤害保护：伤害上限、缓冲区和衰减均暂缓，等待实际伤害曲线。
- 完整轮次末统一扣血：后手拥有结算前最后改写棋盘的权利，可能放大当前反应者优势。
- 只按最终面积决胜：无法提供每回合即时压力，也不能自然提前结束明显失衡的对局。

根据**体验设计**原则，情感来自变化和转折。生命变化与中央归属变化应当形成紧张、回应和逆转，而不是只增加常驻信息。

根据**平衡性**原则，本轮应观察“主动部署、等待反制、储存爆发”三类策略是否都在特定情境下有意义，而不是只比较单个动作的数值是否相等。

根据**优雅性**原则，中央权重同时作用于面积与路径，但不附带额外能力，以最少新规则连接领地、移动、部署和连锁系统。
