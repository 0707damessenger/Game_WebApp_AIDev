# 观鸟挂机游戏 — 设计文档

## 项目概述

以观鸟为主题的桌面挂机游戏网页原型。玩家在等距视角场景中摆放物件、切换地形来形成不同生境，吸引鸟类出现，通过观察拍照解锁图鉴。

## 核心玩法循环

```
摆放物件 + 选择地形模板 → 形成特定生境
    ↓
周期性概率判定 → 鸟类出现/离开
    ↓
小窗口观察 + 调整镜头 + 拍照
    ↓
拍到鸟类 → 解锁图鉴 + 获得积分
    ↓
积分解锁新物件/地形 → 回到第一步
```

## 双窗口模式

- **大窗口（主窗口）**：场景编辑器，全屏展示，用于摆放物件、切换地形、调整摄像机
- **小窗口（独立悬浮窗）**：观察窗/取景器，通过 `window.open` 独立弹出，可拖放至桌面任意位置
- 两窗口通过 `localStorage` 共享游戏状态

## 场景视角

2D 等距/斜45°视角，类似经典模拟经营游戏。物件有高度表现，场景有立体层次感。

## 地形系统

地形决定鸟种池（可能出现哪些鸟类）。当前设计有四种地形模板：

- 高原/山地
- 沼泽/湿地
- 滩涂/海岸
- 溪流/森林

不同地形的鸟种池可重复（广适性鸟类跨多地形，专一性鸟类仅限特定地形）。玩家切换地形模板时，整个场景基础层改变。

## 物件系统

### 物件类型

- **植物**：不同高度/类型的树木、灌木、花草
- **动物/昆虫**：蝴蝶、蜻蜓、松鼠等
- **人工设施**：喂食器、鸟屋、水盆等

### 物件作用

物件影响每种鸟类的出现概率（概率加成）。每种物件对不同鸟有不同的加成值。物件不影响鸟种池（不决定鸟是否可能出现，只影响概率高低）。

### 物件操作

- 从左侧物件面板选择物件，拖放至场景地块上摆放
- 已解锁的物件可免费无限摆放
- 未解锁的物件在面板中显示为锁定状态

## 鸟类出现机制

### 判定流程

1. 系统以固定周期触发判定
2. 遍历当前地形鸟种池中的每种鸟
3. 每只鸟的出现概率 = 基础概率 + 场景中所有物件的加成之和
4. 独立掷骰判定每只鸟
5. 命中：鸟出现在场景中，持续可见直到下次判定
6. 未命中：该鸟本轮不出现
7. 下次判定时重新计算（已出现的鸟可能消失）

### 特点

- 多鸟可同时在场（各自独立判定）
- 玩家可在判定间隙中调整物件布局，影响下一轮概率
- 稀有鸟类基础概率低，需要大量契合物件才能拉高出现率

## 摄像机系统

### 大窗口摄像机

- **平移**：鼠标拖拽移动视角
- **旋转**：绕场景中心旋转摄像机角度
- 摄像机位置和角度实时映射到小窗口

### 小窗口摄像机

- 展示大窗口摄像机同步的画面
- 可独立平移和旋转视角（不影响大窗口）
- 画面带取景框线，模拟相机取景体验

## 拍照系统

### 触发方式

小窗口中提供拍照按钮，点击后对当前镜头画面进行判定。

### 判定逻辑

检查当前镜头视口内是否存在鸟类的可见位置。鸟类入镜即判定成功，不要求完美构图。

### 拍照结果

- 拍到新鸟：解锁图鉴 + 获得首次发现积分
- 拍到已解锁鸟：获得少量重复积分
- 未拍到鸟：无收益

## 图鉴系统

- 目标规模：8-12 种鸟类
- 未发现：显示灰色剪影
- 已拍照：显示鸟类图案（原型阶段用几何图形表示），记录首次拍照时间
- 展示信息：名称、偏好地形、偏好物件

## 积分与解锁

- 初始状态：1 个地形模板 + 少量基础物件
- 积分用途：解锁新物件类型、解锁新地形模板
- 积分来源：拍照奖励（首次发现高分、重复拍摄低分）

## 大窗口 UI 布局

- **顶部工具栏**：物件分类标签（植物/昆虫/设施）+ 积分显示
- **左侧物件面板**：当前分类下的物件列表，区分已解锁/未锁定状态
- **中央**：等距场景视图（Canvas 渲染）
- **底部状态栏**：当前地形名称 + 摄像机坐标信息

## 小窗口 UI 布局

- **中央**：取景器画面（实时渲染当前镜头视角）
- **底部**：拍照快门按钮
- **边框**：取景框装饰线

## 模块拆分（增量开发顺序）

1. **等距场景渲染**：Canvas 等距网格、地形模板渲染、场景基础
2. **物件系统**：物件面板、拖放摆放、物件渲染
3. **摄像机模块**：平移+旋转控制、视口变换、大小窗口同步
4. **小窗口取景器**：独立悬浮窗、取景框、拍照按钮
5. **生境与鸟类生成**：地形-鸟种池映射、物件概率加成、周期性判定
6. **拍照判定与图鉴**：入镜检测、图鉴解锁、拍照奖励
7. **积分与解锁**：积分累计、物件/地形解锁、进度保存

## 配置与资源策略

- 所有属性数值和功能开关在 HTML 文件顶部 `CONFIG` 对象中维护
- 原型阶段使用纯色几何图形占位，不依赖美术资源
