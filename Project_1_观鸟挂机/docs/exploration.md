## 一、候选池存档（已决策的发散选项）

以下为前期头脑风暴产生的候选方案。**最终选项已写入 design.md，此处仅存档落选项与取舍依据**，便于回溯。原始可视化稿见 [`../.superpowers/brainstorm/default/content/`](../.superpowers/brainstorm/default/content/)。

### 1. 场景视角（已选：等距/斜 45°）

- **A 俯视 Top-Down**：简单直观、易摆放规划，但缺乏纵深感与"观察"沉浸感。落选。
- **B 等距/斜 45°** ✅：兼具俯视的规划感与立体层次，物件有高度表现。→ 已落地，见 design.md「场景视角」。
- **C 侧视/横版**：观察窗代入感强，但编辑空间受限于横向维度，地形变化主要靠高度。落选。

### 2. 双窗口关系（已选：主窗口 + 独立弹出小窗）

- **A 同页面双面板**：编辑器与取景器始终同屏，便于边调边看，但缺少"桌面挂机"的分离感。落选。
- **B 主窗口 + 独立弹出小窗（`window.open`）** ✅：取景器为独立悬浮小窗，可拖至屏幕任意位置，贴合桌面挂机体验。→ 已落地。
- **C 双标签页/双独立窗口**：最接近真正的桌面多窗口，但操作更分散。落选（其 `localStorage` 状态同步机制被方案 B 采纳）。

### 3. 大窗口 UI 布局（已选：方案 A）

- **方案 A 顶部工具栏 + 左侧物件面板** ✅：分类标签置顶、物件列表居左、场景居中、状态栏置底。→ 已落地，见 design.md「大窗口 UI 布局」。
- **方案 B 底部工具栏 + 浮动物件面板**：场景占满、面板浮于场景之上。落选。
