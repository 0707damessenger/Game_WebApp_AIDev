双窗口模式 — 大窗口 vs 小窗口的布局关系

这两种窗口在实际使用中是什么关系？选一个最接近你设想的

A

同页面双面板

同一浏览器页面内，左侧大面板是场景编辑器，右侧小面板是观察窗/取景器。两者始终同时可见，方便一边调整场景一边观察结果。

场景编辑器
拖动摆放植物、改变地形
取景器/观察窗
镜头画面、拍照按钮
B

主窗口 + 独立小窗 (Popup)

场景编辑器在主浏览器窗口全屏展示；观察窗是一个独立弹出的小窗口（类似桌面悬浮窗），可随意拖放到屏幕任意位置，模拟"桌面挂机"的体验。

主窗口
场景编辑器（全屏）
观察窗
悬浮小窗
可拖动
C

双标签页 / 两个窗口

大窗口和小窗口是两个独立的浏览器标签页（或两个独立窗口），通过 localStorage 等共享游戏状态。更接近真正的"桌面多窗口"体验。

标签页 A
场景编辑器
通过 localStorage 同步
标签页 B
观察窗 / 取景器
通过 localStorage 同步
