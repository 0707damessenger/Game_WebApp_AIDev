场景视角 — 摄像机以什么角度观察场景？

这个决定影响场景编辑器的操作方式、生境的呈现效果，以及小窗口取景器的画面风格

A

2D 俯视视角 (Top-Down)

摄像机从正上方俯视场景，类似地图编辑器。简单直观，易于摆放物件和规划生境，但缺乏纵深感和"观察"的沉浸感。

草地 + 树木 + 小径 → 俯视视角
B

2D 等距/斜45°视角 (Isometric)

摄像机以45度斜角俯瞰，兼具俯视的规划感和立体的层次感。物件有"高度"表现，场景更有深度，是模拟经营类游戏的经典视角。

树木层次分明 → 等距视角
C

2D 侧视/横版视角 (Side-View)

摄像机从侧面水平观察场景，有前景/背景层次。非常有"观察窗"的感觉，但场景编辑空间受限于横向维度，地形变化主要在高度上。

前景/背景分层 → 横版视角
