# 鸟种特征数据来源（模糊匹配）

模糊匹配候选所用的本地特征表 `prototype/js/bird_traits.js`（`window.BIRD_TRAITS`）由本说明所列公开数据集按**学名（拉丁名）**联结生成。特征维度为 **体型 / 主色 / 行为 / 栖息地** 四项（姿态维度已移除）。

## 数据源

| 维度 | 数据源 | 许可 / 性质 | 链接 |
|---|---|---|---|
| 体型 size | 《中国鸟类生活史和生态学特征数据集》(体重/体长) 或 AVONET `Mass` | 学术发表 / CC 署名 | https://www.biodiversity-science.net/CN/10.17520/biods.2021201 · https://figshare.com/articles/dataset/16586228 |
| 栖息地 habitats | AVONET `Habitat`(9 类) | CC 署名 | https://figshare.com/articles/dataset/16586228 |
| 行为 behaviors | EltonTraits 1.0 觅食层 + AVONET `Primary.Lifestyle` | CC BY 4.0 | https://doi.org/10.6084/m9.figshare.c.3306933.v1 |
| 主色 colors | HBW 插图 RGB 数据集（24 色聚类） | 学术发表（Dryad） | https://datadryad.org/dataset/doi:10.5061/dryad.70rxwdc6s |

## 映射规则（设计层）

- **体型**：连续的体重/体长按阈值分入 5 档（很小 / 小型 / 中型 / 大型 / 很大）。
- **栖息地**：AVONET 的 9 类栖息地映射到本项目 8 类（湿地·湖泊 / 河流 / 林地 / 灌丛 / 草地 / 农田 / 城市 / 海岸）。
- **行为**：由 EltonTraits 觅食层（水下 / 水面 / 地面 / 林下 / 林冠 / 空中）与 AVONET 生活型推导（游水 / 涉水 / 潜水 / 飞行 / 停栖 / 地面觅食）；「盘旋 / 悬停 / 鸣叫」无可靠数据源，置空。
- **主色**：HBW 插图的 24 色聚类映射到本项目 8 主色（白 / 黑 / 灰 / 褐 / 黄 / 绿 / 蓝 / 红）。

## 分层与精校机制

- **打底层**：按上述数据源全量自动生成全国正式名录各种的特征，写入 `bird_traits.js`。
- **精校层**：常见种的人工校正独立维护于 `tools/trait_overrides.json`（按学名键），构建时覆盖打底层，**重新生成不被冲掉**。
- 缺源种的对应维度**留空**，不杜撰。

## 处理边界与注意

- 特征表仅用于「缩小识别方向」的候选建议，不替代用户确认，也不等同图像/声音识别结果。
- 原型运行时不访问任何在线特征服务；全部特征来自本地静态表。
- 各数据集分类版本可能与名录 v10.0 略有出入，联结命中率在构建脚本中打印核查。
- 公开原型或产品化前，应确认各数据集的授权与署名要求；如更换授权文件，应保持同样的数据边界重新生成。

## 后续注意

具体映射阈值（体型分桶边界、颜色聚类归并表等）属可调数值，落在构建脚本与 `CONFIG`，不在本文档记录，以免调试时反复改文档。
