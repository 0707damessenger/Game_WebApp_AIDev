# 鸟类名录数据来源

## 当前原型数据

- 来源仓库：`makenv/bird-list-en`
- 来源文件：`v10_0.csv`
- 来源说明：该仓库描述为“中国观鸟年报-中国鸟类名录”，并包含《中国观鸟年报-中国鸟类名录 v10.0》原始表格文件。
- 本项目使用方式：提取具有中文名与拉丁学名的正式物种条目，生成原型本地静态 `BIRD_CATALOG`。

## 当前处理边界

- 只保留中文名与学名。
- 不加入英文名、别名、拼音首字母、保护等级或备注字段。
- 不把科/目标题行作为鸟种。
- 原型运行时不访问在线名录服务。

## 后续注意

公开原型或产品化前，应确认名录数据授权与署名要求；如后续改用官方授权文件，应保持同样的数据边界重新生成本地名录。
