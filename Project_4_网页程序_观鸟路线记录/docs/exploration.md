# 观鸟路线记录 · 探索与候选

> 本文档存放尚未收敛、未确认落地的内容：备选方案、待定选型、暂不纳入的方向。
> 纪律：任一条目确认落地时，先写入 `docs/design.md`，再从本文档移除，避免双份真相。

## 1. 地图国内瓦片源选型（待定）

当前阶段先用国外免费公共瓦片源（零配置起步）。后续为保证国内稳定访问需切换国内源，候选方向：

- 高德地图瓦片：国内访问稳定，需申请 API key。
- 天地图瓦片：国家级公共服务，需申请 key。
- 其他国内可用源。

切换的已知门槛：国内源与国际源坐标体系不同，定位与鸟种落点需做坐标纠偏。具体选哪一个、以及纠偏方案，待进入该模块时再定。

## 2. 鸟种模糊匹配的特征维度（待定）

需求中模糊匹配为低优先、当前不实现。其交互方向（来自需求）：用户选择若干特征标签完成一条「不确定种名」的记录，并被引导前往 Merlin 进一步识别。

待定：具体采用哪些特征维度（如颜色、体型、翼展等）、各维度的取值集合。进入该模块前不固化。

## 3. 分享与导入的具体形态（待定）

后续模块。需求方向：以链接或图片分享，他人复制链接导入。

待定：分享产物形态（链接 / 图片各自承载什么）、导入的数据边界与去重规则等。

## 4. 鸟类名录数据范围（待定）

当前阶段采用真实中文鸟类名录作为搜索来源。待定：名录的覆盖范围（常见种子集起步还是全量）、数据获取与更新方式。原型先以一份可用名录起步，规模在实现时确定，不在设计层固化。
