# 观鸟路线记录 · 探索与候选

> 本文档存放尚未收敛、未确认落地的内容：备选方案、待定选型、暂不纳入的方向。
> 纪律：任一条目确认落地时，先写入 `docs/design.md`，再从本文档移除，避免双份真相。

## 1. 分享与导入的真实服务形态（待定）

当前已确认并进入设计文档：基于 CloudBase 做真实分享链接，生成固定分享快照；持链接可导入；导入采用个人页粘贴链接方式；导入后保存到当前身份收藏线路并标记为导入记录；敏感鸟点在分享快照中剔除；重复导入打开已有记录，不新增副本。

后续待定：服务器短链接如何生成、链接失效与更严格权限策略、分享记录更新策略、图片或二维码分享是否纳入同一模块，以及更完整的跨设备兼容处理。

后端平台已锁定为微信云开发 CloudBase（见 `docs/design.md`）。短链、二维码/图片分享与更严格权限等深化能力将基于云函数 / 云存储实现，但具体形态仍待定。

## 2. 鸟类名录后续搜索增强（暂不纳入本次）

已确认当前阶段采用全国正式鸟类记录作为本地静态名录，并只支持中文名与学名搜索。

以下方向暂不纳入本次：

- 拼音首字母搜索。
- 别名与英文名搜索。
- 附录、存疑、外来逸出等条目的搜索展示与标记。
- 在线更新或周期性同步名录。

## 3. 后端接入（CloudBase）待定项

后端平台已锁定为微信云开发 CloudBase，节奏为「先在网页原型用 Web 端 SDK 打通后端，再议小程序迁移」（已写入 `docs/design.md`）。以下尚未收敛：

- 分享短链 / 更严格导入校验 / 导出文件格式的具体形态。
- 小程序迁移的启动时机与界面改写范围。
