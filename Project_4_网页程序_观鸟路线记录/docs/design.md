# 观鸟路线记录 · 设计文档

> 本文档是开发契约。后续开发以此为准；设计变更必须先改本文档再改原型。
> 内容只描述设计层面（玩法、规则、玩法循环、模块拆分、UI 布局、交互逻辑），不含实现细节与精准数值。

## 1. 项目概述

一站式记录观鸟路线的应用：用户边走边记录行进路线，在路线途经点记录所见鸟种，结束后生成路线图并查看本次记录。解决现有工具「记录鸟种」与「记录路线」彼此割裂的问题。

- **目标平台**：手机端（竖屏、触摸操作），最终上线微信小程序/安卓程序。按手机真机使用逻辑设计；开发期可用浏览器手机视口验证功能闭环，最终手感以手机真机为准。
- **当前阶段范围**：实现「核心记录闭环」「个人入口与历史记录列表」「历史记录编辑·删除·落点拖动」「全国正式鸟类名录扩展」「鸟种模糊匹配」「国内稳定地图源切换」「分享导入交互骨架」与「本地收藏线路」。账号、设置、真实分享服务等均为后续模块（见第 7 节）。

## 2. 核心功能

核心循环（单次记录）：

```
开始记录 → 选择起点 → 行进（持续记录轨迹）
        → 途经点添加鸟种（可多次）
        → 结束 → 生成路线图 → 查看本次记录
        → 从个人入口查看历史记录列表 → 打开已保存记录
```

状态机：

- **未开始**：主界面，等待开始记录。
- **选起点**：打开地图、定位当前点为起点，确认后进入记录中；返回则回到未开始。
- **记录中**：持续记录行进轨迹，可多次添加鸟种。
- **已结束**：生成并展示「本次记录」（路线图 + 鸟种清单）。
- **个人页**：从主界面进入，展示个人相关入口；点击「历史记录」后进入历史记录列表页，点击「收藏线路」后进入收藏线路列表页。
- **历史记录列表页**：展示本地历史记录列表，并可打开其中一条历史记录。
- **收藏线路列表页**：展示本机历史记录中已收藏的路线，并可打开其中一条收藏记录。
- **中止**：放弃本次记录，不生成任何记录，回到未开始。

## 3. 规则与交互逻辑

### 3.1 开始记录与选择起点

- 点击「开始记录」后打开地图，自动定位当前位置作为起点。
- 确认起点后进入「记录中」；选择返回则回到主界面、不开始。

### 3.2 行进与轨迹

- 进入「记录中」后，应用持续记录用户的行进路线，结束时据此生成路线图。
- 定位来源可在配置中切换：
  - **真实 GPS**：真机使用时采集真实定位。
  - **模拟行走**：开发验证期使用，在地图上以最简操作产生行进轨迹。
  - 两种来源向上层提供一致的位置数据，业务逻辑不区分来源。
- 真实 GPS 模式下，开始记录时请求浏览器定位权限；成功获取当前位置后进入记录中，并随定位变化持续追加轨迹点。
- 真实 GPS 不可用、权限被拒绝或定位失败时，界面给出提示并停留在选起点状态，不自动生成虚假的真实轨迹。

### 3.3 添加鸟种

- 记录中可随时添加鸟种，该条记录**自动关联当前所在位置**，落点位于路线上。
- 单条鸟种记录包含：
  - **鸟种**：按中文名或学名搜索匹配真实鸟类名录后选定。
  - **数量**：步进增减。
  - **备注**：预设标签（可多选）+ 自定义文本。初版预设标签为：成鸟、亚成、雌、雄、飞行。
- 已添加的鸟种落点可被再次点选，点选后进入预览；用户可继续编辑鸟种、数量、备注，或删除该条落点记录。
- 当多个鸟种落点距离极近、难以单独点选时，界面应将这些落点合并为一个可点选的组合点；点选组合点后先展示其中包含的记录，再选择具体记录进行编辑。
- 鸟种落点支持显示模式开关：默认只显示落点标记；打开后在路线上显示鸟种名，便于核对记录。
- 当前阶段的鸟类名录以全国正式鸟类记录为主；附录、存疑、外来逸出等条目暂不混入普通搜索结果。拼音首字母、别名与英文名搜索不在本次范围内。
- **模糊匹配**用于用户无法确认具体鸟种时记录一条「未确定鸟种」。用户按地点、时间、体型、颜色、行为、栖息地与姿态等特征缩小方向；地点和时间随鸟点自动关联，手动特征由用户选择。
- 模糊匹配可给出本地候选建议，但候选只作为进一步识别方向，不替代用户确认，也不宣称等同 Merlin 的识别结果。
- 通过模糊匹配保存的鸟点不记具体种名；后续可继续编辑其数量、备注、特征与候选建议。

### 3.4 结束与中止

- **结束**：生成路线图并进入「本次记录」页；本次记录存于本地。
- **中止**：放弃并丢弃本次记录，不生成历史。
- 结束入口位于记录主界面右上角；点击后弹出确认，提供三种选择：保存并结束 / 中止并丢弃 / 继续记录。中止为危险操作，需经此确认、避免误触。
- 本次记录保存后可在结果页直接收藏或进入编辑，不要求用户先回到历史列表再打开该记录。

### 3.5 个人入口与历史记录

- 主界面提供「个人」入口，进入独立个人页后展示「历史记录」「收藏线路」入口与其他个人功能占位。
- 点击「历史记录」后进入单独的历史记录列表页。
- 每次保存并结束的路线记录进入历史列表，历史列表按最新保存优先展示。
- 点击历史记录后进入只读查看，呈现该记录的路线图、鸟种落点、概要与鸟种清单。
- 历史记录支持**编辑与删除**（见 3.6）；分享与导入为当前交互骨架，账号同步仍为后续模块。
- 已保存的历史记录支持**收藏 / 取消收藏**。收藏仅作用于本机历史记录，不创建独立副本，也不产生账号同步。
- 点击「收藏线路」后进入单独的收藏线路列表页；列表只展示已收藏的历史记录，按历史记录原有排序展示。没有收藏记录时显示空状态。
- 历史列表与收藏列表中，点击记录主卡片打开详情；收藏以星标入口呈现；删除作为弱化的次级操作并保留二次确认。
- 删除一条历史记录时，其收藏状态随该记录一并删除，不额外保留收藏副本。

### 3.6 历史记录编辑与删除

- 打开历史记录后默认只读查看，可切换进入**编辑模式**。编辑采用统一保存模型：改动在保存前不写入历史，点「保存」才生效，点「取消」放弃全部改动并还原为编辑前状态。
- 本次记录保存后的结果页也可进入编辑模式；编辑规则与历史记录编辑一致。
- 编辑模式下，可对鸟种落点进行：
  - 编辑鸟种信息（鸟种、数量、备注），复用记录中的鸟点编辑交互。
  - 删除单个鸟种落点。
  - **拖动落点位置**：落点吸附到行进轨迹上，始终落在已走过的路线上。
- 行进轨迹本身不可编辑；本阶段编辑只针对鸟种落点。
- 编辑模式需要明确提示用户可点选鸟点进行编辑/删除，也可拖动鸟点调整位置。
- 删除整条历史记录从历史列表发起，属危险操作，需二次确认。
- 保存后，记录概要（鸟种数、总只数等）依最新内容重新生成。

### 3.7 分享与导入交互骨架

- 本次记录页与历史记录只读查看页均提供「分享」入口。
- 当前阶段的分享入口打开分享弹层，展示记录摘要、完整路线与鸟点位置会被分享的位置敏感提示，以及真实服务器链接服务尚未接入的状态。
- 当前阶段不生成真实短链接、不生成图片或二维码，也不把记录数据写入 URL。
- 个人页提供「导入分享链接」入口；用户可打开导入弹层并输入分享链接。
- 当前阶段导入弹层仅展示服务待接入的预览占位，不把输入内容保存为历史记录。
- 后续真实导入能力接入后，同一条分享记录重复导入时不新增副本，而是提示已存在并打开已有记录。

## 4. UI 布局

整体为手机竖屏。地图作为记录场景的主背景，当前阶段直接采用真实地图瓦片，不使用几何假地图。当前默认采用天地图国内瓦片源，并保留公共瓦片源作为开发回退。地图瓦片与鸟类名录属于核心数据源；除这两类核心数据源外，原型阶段不引入美术资源，界面图形与标记使用纯色几何占位。

### 4.1 记录主界面（记录中）

- 地图全屏铺底，行进轨迹叠加其上。
- **头顶**：状态胶囊，显示本次时长、距离、已记录鸟种数。
- **底部**：记录中仅显示一个「添加鸟种」大按钮（主操作，拇指可达）；选起点阶段不显示该按钮。
- **右上角**：「结束」按钮（角落不易误触、又一步可达），点击弹出结束确认。
- **地图工具**：不提供独立缩放按钮；手机端依赖双指缩放，桌面端依赖鼠标滚轮缩放。提供定位到当前位置入口，以及鸟种名显示开关，用于在落点标记与落点名称之间切换。
- **底图异常提示**：地图瓦片加载失败时给出轻提示或嵌入式提示，不遮挡首屏主按钮与记录主操作。

### 4.2 添加鸟种弹层

从底部弹出，覆盖在地图上：

- 鸟种名称搜索框，结果列表展示匹配的中文名（附学名）。
- 精确搜索与模糊匹配作为并行模式切换；精确搜索用于确认具体鸟种，模糊匹配用于保存未确定鸟种。
- 鸟种搜索框为空时显示空状态，不默认展示名录开头条目。
- 模糊匹配模式展示特征选择区；至少选择一个手动特征后才可保存未确定鸟点。
- 模糊匹配结果展示候选建议与继续前往 Merlin 进一步识别的提示。
- 数量步进器。
- 备注：预设标签多选 + 自定义文本输入。
- 「添加到当前位置」确认；提示本条将记录在当前所在位置。

### 4.3 本次记录页（结束后）

- **顶部概要**：日期 / 地点、时长、距离、已确认鸟种数、未定记录数与总只数。
- **中部路线图**：完整轨迹 + 各鸟种落点，点击落点可定位。
- **鸟种清单**：本次所有鸟点记录（名称或「未确定鸟种」、特征/备注、数量），点击条目高亮对应落点；与记录主界面的落点预览/编辑逻辑保持一致。
- **底部**：返回主界面；收藏 / 取消收藏；编辑；分享入口打开分享弹层，当前用于展示分享交互骨架与服务待接入状态。
- 记录详情页根据来源显示一致的标题语义：本次记录、历史记录或收藏线路。

### 4.4 个人页（当前阶段）

- 从主界面进入，作为独立全屏界面打开，整体仍按手机竖屏触摸操作设计，不作为底部栏覆盖在地图上。
- **历史记录入口**：作为个人页的主要可用入口；点击后进入历史记录列表页。
- **收藏线路入口**：进入本机已收藏路线列表；用于快速回看标记过的历史路线。
- **导入分享链接入口**：打开导入弹层，用于展示后续短链接导入流程的交互骨架。
- **占位区**：个人信息、设置、登录 / 登出等入口以不可用状态显示，提示其为后续模块。
- **返回**：可回到主界面，不影响已有历史记录。

### 4.5 历史记录列表页（当前阶段）

- 从个人页的「历史记录」入口进入。
- 作为独立全屏界面打开，不作为底部栏覆盖在地图上。
- 展示本地已保存记录；条目包含记录时间、地点概要、路线距离、鸟种数与总只数。无历史记录时显示空状态。
- 记录主卡片负责打开详情；列表项提供星标收藏 / 取消收藏入口，收藏状态变化立即反映到收藏线路列表。
- 点击单条历史记录后进入只读查看；返回时回到历史记录列表页。
- 删除整条记录作为弱化次级入口，删除前二次确认。
- 提供返回个人页的入口。

### 4.6 收藏线路列表页（当前阶段）

- 从个人页的「收藏线路」入口进入。
- 作为独立全屏界面打开，不作为底部栏覆盖在地图上。
- 展示本机历史记录中已收藏的路线；条目展示方式与历史记录列表一致。无收藏记录时显示空状态。
- 点击单条收藏记录后进入只读查看；返回时回到收藏线路列表页。
- 收藏线路列表不创建独立副本；取消收藏后，该记录从收藏列表移除，但仍保留在历史记录列表。
- 提供返回个人页的入口。

### 4.7 历史记录编辑模式（当前阶段）

- 在记录详情页提供「编辑」入口；进入后顶部显示「保存」/「取消」和简短操作提示。
- 地图上的鸟种落点变为可拖动，拖动时吸附到行进轨迹；点选落点可编辑其信息或删除该落点。界面需明确提示这两种编辑方式。
- 保存或取消后回到只读查看；保存后概要按最新内容刷新。
- 历史记录只读查看页提供收藏 / 取消收藏入口，状态与列表页保持一致。

## 5. 逻辑模块拆分（设计层）

- **定位源**：提供真实 GPS 与模拟行走两种来源，对上层暴露一致的位置数据；来源由配置切换。
- **地图与轨迹**：真实瓦片底图 + 行进轨迹的绘制与更新；地图底图支持在天地图国内源与公共回退源之间切换。
- **鸟种记录**：支持确认鸟种与未确定鸟种两类记录；确认鸟种来自名录搜索，未确定鸟种来自模糊匹配特征与候选建议，两类记录都包含数量、备注并与当前位置关联。
- **记录数据模型**：一次记录 = 行进轨迹 + 一组带位置的鸟种记录 + 概要信息。
- **结果呈现**：由记录数据生成路线图与鸟种清单。
- **历史记录列表**：保存已结束记录的快照，支持从列表进入查看、编辑与删除。
- **历史记录编辑与删除**：围绕已保存记录提供鸟种落点信息编辑、单点删除、落点拖动吸附轨迹、整条记录删除与保存/取消流程。
- **本地收藏线路**：在本机历史记录上标记收藏状态，并从个人页进入收藏线路列表；收藏不脱离原历史记录独立存在。
- **分享与导入交互骨架**：围绕已保存记录展示分享入口、导入入口、位置敏感提示与服务待接入状态；当前不产生跨设备数据流转。
- **配置**：全项目唯一配置源，集中承载所有数值与功能开关（含定位来源、地图底图等）。

## 6. 数据与资源策略

- **记录持久化**：本次记录在结束后保存到本地，保证结束后可查看；已保存记录进入本地历史列表，并可在本地编辑、删除与标记收藏。收藏状态只保存在本机历史记录中；旧记录没有收藏状态时按未收藏处理。跨设备同步属后续模块。
- **鸟种名录**：直接采用真实中文鸟类名录作为搜索数据来源，当前阶段扩展为全国正式鸟类记录，并以内置本地静态名录保证原型运行时不依赖在线服务。
- **模糊匹配候选**：当前仅基于本地规则和用户特征给出候选建议；原型不联网调用 Merlin、不接入图像或声音识别，也不引入外部鸟类特征数据库。
- **地图底图**：直接采用真实地图瓦片。当前默认接入天地图国内瓦片源，使用矢量底图与中文注记，并保留公共瓦片源作为开发回退。本阶段不改变路线、定位与鸟种落点的数据结构；若后续更换为需要额外坐标纠偏的地图源，再作为独立模块确认。
- **分享导入**：当前只提供交互骨架，不上传记录、不生成真实可导入链接，也不从外部链接写入历史记录。未来接入真实分享服务时，分享内容默认包含完整路线与鸟点位置，并按重复导入不新增副本的规则处理。
- **占位资源**：地图瓦片与鸟类名录不做占位；其他界面图形、按钮、轨迹、落点与状态标记使用纯色几何图形，不依赖美术资源。
