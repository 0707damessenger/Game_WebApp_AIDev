# Spellatoon 探索记录

## 已确认的方案选择

### 玩法验证优先

第一版采用玩法验证优先方案：完整实现当前规则，使用清晰的路径高亮、染色、卡牌收走和得分提示，控制动效强度，优先观察连锁、吞噬、移动、部署和染色是否容易理解、是否形成策略。

### 放弃的候选方案

- 视觉表现优先：暂不加入更强的喷溅、镜头和复杂庆祝效果，避免动效掩盖规则反馈。
- 调试验证优先：暂不把大量测试入口暴露在主要体验中，只保留服务于规则复核的必要测试能力。
- 同一电脑轮流操作：暂不作为主要联机形态，第一版直接验证两台设备的局域网信息隔离。
- 先选择手牌再预览：暂不采用。当前预览直接根据悬停目标卡牌的数字进行假设模拟。
- 锁定卡牌格：不采用。预览的目的为空格策略评估，只有空格可以锁定。

## 当前验证假设

- 连锁也移除参与卡牌后，清场和得分反馈会更明确，但需要观察棋盘是否过快变空。
- 数字卡牌同时用于移动与部署，应该形成资源取舍，而不是让数字只承担单一用途。
- 空格预览能帮助玩家提前理解路径和得分，从而降低连锁与吞噬的学习成本。
- 明亮纸张背景可以在保持卡通色块的同时，提升路径、数字和颜色归属的可读性。

这些内容是首轮试玩时的观察假设，不是新增规则；若试玩后需要改变规则，必须先更新 `design.md`，再修改原型。
