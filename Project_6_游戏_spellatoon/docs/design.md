# Spellatoon 设计文档

## 核心目的

制作一个支持两台局域网设备本地联机的双人对战卡牌游戏原型。玩家通过角色移动、数字卡牌部署和颜色扩张争夺棋盘，利用同数字卡牌形成连锁或吞噬来获得分数，并在短局结束后以分数决定胜负。

第一轮验证重点是：玩家能否理解连锁、吞噬和得分；移动、部署与染色是否能形成有意义的策略；两台设备是否能在不泄露手牌的前提下实时完成一局。

## 游戏结构

- 游戏名称为 Spellatoon，名称结合 spell 与 Splatoon。
- 对局由两名玩家组成，每名玩家操作一个自己的角色。
- 棋盘为固定的小型方格棋盘，双方角色从两个对角位置开始。
- 每名玩家拥有自己的代表色；角色、已部署卡牌、地块颜色和双方分数属于公共信息。
- 数字卡牌是唯一牌类。每张牌都可以被选择用于移动或部署，不区分移动牌与部署牌。
- 数字卡牌的数字范围为低位连续数字，允许重复；具体范围由原型配置承载。
- 双方各自拥有私有手牌，手牌数量存在上限；开局手牌补满。
- 回合开始时为当前玩家补牌，但补牌不会超过手牌上限。
- 双方各完成相同数量的短回合后，进入最终结算。

## 回合规则

- 系统在对局开始时通过硬币决定先手。
- 当前玩家回合开始时补牌。
- 当前玩家最多执行一次移动和一次部署，移动与部署的先后顺序不做规定，也可以放弃其中任意行动。
- 玩家完成行动后点击结束回合，回合才交给对手。
- 数字卡牌用于移动或部署后立即从手牌中移除。
- 无效操作不会消耗数字卡牌，不会消耗对应行动次数，也不会改变棋盘。

## 移动规则

- 使用数字为 N 的数字卡牌移动时，角色最多移动 N 格，且至少移动一格。
- 每一步只能横向或纵向移动，移动过程中允许任意转弯。
- 角色可以经过或停留在已有数字卡牌的格子。
- 棋盘外的位置均为无效位置。
- 玩家可以放弃移动行动；没有合法移动路径时，保留该数字卡牌并跳过移动。
- 移动成功后立即同步角色位置和公共回合状态。

## 部署规则

- 部署只能发生在自己角色执行部署时所在的格子。
- 角色所在格已有任意数字卡牌时不能部署。
- 合法部署会在该格放置数字卡牌，并立即将该格染成部署者的代表色。
- 即使该格原本是对手颜色，合法部署也可以改为部署者的颜色。
- 部署成功后立即消耗所选数字卡牌，并进入连锁或吞噬判定。

## 连锁与吞噬

- 连锁与吞噬只检查棋盘上已经部署的数字卡牌，不检查尚未部署的手牌。
- 判定只发生在包含本次新部署卡牌的横向和纵向路径上；之前已经存在的关系不会重复触发。
- 两张卡牌必须处于同一横行或竖列，且卡牌之间的空格数量不超过允许范围；中间已有的其他数字卡牌不阻挡路径。
- 同一方向上有多张相关卡牌时，合并为一条由最外侧相关卡牌连接而成的路径，路径格子只计算一次。
- 连锁参与卡牌必须与本次新部署卡牌数字相同，并且属于同一玩家。连锁路径染成该玩家颜色。
- 连锁路径上的参与卡牌全部移除，包括本次新部署卡牌；中间不参与判定的其他数字卡牌保留。
- 不同玩家的同数字卡牌形成相关路径时，视为吞噬，由本次新部署卡牌所属玩家作为后手。
- 吞噬路径上的起点卡牌、终点卡牌和中间经过的全部卡牌都移除，整条路径染成后手玩家颜色。
- 一次部署同时形成横向和纵向关系时，两条方向都结算并分别计分。
- 横向和纵向以同一份部署完成后的棋盘状态进行判定；卡牌移除取两条路径的并集，交叉格只移除一次。
- 连锁和吞噬都只结算当前部署直接形成的效果，移除的卡牌不会再次触发新的连锁或吞噬。

## 分数与结算

- 连锁与吞噬均按照路径经过的全部格子计算上色数量，已经是该玩家颜色的格子也计入。
- 一次效果的得分为：参与判定的数字乘以该效果路径经过的格子数。
- 连锁分数归参与连锁且与新部署卡牌同属一方的玩家。
- 吞噬分数归本次新部署卡牌所属玩家。
- 横向和纵向分别计算得分，即使两条路径有交叉格也分别计分。
- 双方分数在对局中始终公开。
- 双方各完成规定回合后强制结算；分数较高者获胜，分数相同判定为平局。

## 联机与信息边界

- 对局支持两台处于同一局域网的设备。
- 一台设备创建房间并作为房主，另一台设备通过房主提供的局域网地址加入。
- 两名玩家都加入后，房主才能点击开始对局。
- 房主作为本局裁判，负责保存完整对局状态、验证操作和执行连锁、吞噬及得分。
- 完整对局状态包括棋盘、双方角色、已部署卡牌、地块颜色、双方手牌、双方分数和回合进度。
- 每台设备只接收公共信息和本设备所属玩家的手牌，不接收对手手牌。
- 公共信息包括棋盘、角色位置、已部署卡牌的数字与颜色、地块颜色、双方分数、当前回合方和连接状态。
- 当前玩家设备显示自己的手牌与行动按钮；等待对手时只显示公共棋盘、双方分数、回合状态和等待提示。
- 移动、部署和结束回合都提交给房主裁判端，由裁判端验证并在成功后实时同步给双方。
- 断线时保留房间与对局状态；断线设备重新加入后继续当前对局。

## 界面布局

- 采用棋盘下方控制台布局，棋盘保持页面视觉中心。
- 控制台只展示当前设备所属玩家的手牌、分数、当前回合进度、可用行动和结束回合操作。
- 对手只通过公共信息呈现，包括代表色、角色位置、已部署卡牌、地块颜色和公开分数，不展示对手手牌。
- 对局开始时展示硬币先手结果，再进入先手玩家的行动界面。
- 对手行动期间，控制台切换为等待状态；收到移动或部署同步后，棋盘立即更新。
- 移动操作显示角色可到达范围，并允许玩家逐格选择一条符合数字上限的横纵路径。
- 部署操作高亮角色当前格；已有卡牌的格子提示为不可部署。

## 自由预览

- 自由预览是只读的公共棋盘分析功能，不消耗行动、不消耗手牌、不改变真实棋盘。
- 鼠标悬停在空格或卡牌格时，高亮该格横向和纵向允许预览范围内的已部署卡牌。
- 只有空格可以被点击锁定；卡牌格不能锁定，只能作为被高亮和悬停查看的目标。
- 点击空格后锁定该格，表示假设在该空格部署一张当前玩家颜色的数字卡牌。
- 锁定空格后，鼠标悬停某张被高亮的已部署卡牌，以该卡牌的数字作为假设部署数字，自动模拟连锁或吞噬效果。
- 预览显示潜在效果类型、完整路径、会被移除的卡牌、路径颜色和预计得分。
- 预览不要求假设数字实际存在于当前手牌，只用于比较空格的潜在策略。
- 移开预览或点击其他空格时，解除原锁定并重新选择预览位置。
- 等待对手期间也可以使用预览，因为预览只读取公共棋盘，不读取对手手牌。

## 视觉与动效

- 视觉基调为卡通、明亮、强色块和清晰涂色反馈，参考 Splatoon 的涂色竞争感，但不直接使用其美术资源。
- 第一版采用明亮纸张方向：浅色背景承托高亮代表色，保证数字、路径和分数变化清晰可读。
- 原型使用纯色几何图形作为角色、卡牌、地块和其他视觉占位，不依赖外部美术资源。
- 普通部署先显示单格染色；连锁显示路径高亮、染色和参与卡牌收走；吞噬显示整条路径染色和路径上卡牌收走。
- 动效优先表现路径与结果，不遮挡卡牌数字、颜色归属和分数变化。
- 开局硬币、连锁、吞噬、得分、回合切换和最终结算都需要有明确的状态提示。

## 验证标准

- 两台局域网设备可以加入同一房间，房主可以在两名玩家加入后开始对局。
- 两台设备可以完成一局，先手、回合切换、补牌、移动、部署和结束回合流程正确。
- 双方都能看到公共棋盘、双方分数、角色位置、卡牌数字与颜色，但无法看到对方手牌。
- 移动、部署、棋盘边界、已占用格、行动次数和无效操作均符合规则。
- 能验证同色连锁、不同色吞噬、中间卡牌、同一直线多张卡牌、横纵同时触发、路径交叉和卡牌移除。
- 连锁和吞噬的路径、染色、卡牌移除与得分可在界面中理解和复核。
- 自由预览可以从空格锁定位置，并正确展示不同数字假设下的连锁或吞噬策略。
- 双方各完成规定回合后强制结算，高分胜出，同分为平局。
- 第一轮试玩重点观察玩家是否能理解连锁与吞噬的区别，以及移动、部署和染色是否产生策略选择。
