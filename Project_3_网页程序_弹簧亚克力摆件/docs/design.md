# 弹簧亚克力摆件 - 设计文档

## 1. 概念与愿景

一个精致的弹簧亚克力摆件交互原型。底部是简约的固定支架底座，上方通过金属弹簧连接着透明的亚克力几何图形。用户可以鼠标在 XY 平面自由拖动亚克力图形拉伸或压缩弹簧，松开后图形会基于物理弹簧阻尼振动自然回弹。整体呈现一种精致、有趣、可交互的桌面摆件体验。

## 2. 设计语言

### 美学方向
- 极简主义桌面摆件风格，干净、现代、有质感
- 透明亚克力的通透感 + 金属弹簧的工业质感 + 几何图形的简约美

### 配色方案
- 背景：暖色渐变 `#f5f0e8` → `#e8e0d5`
- 亚克力图形：半透明渐变 `rgba(100, 180, 255, 0.4)` + 边框高光
- 弹簧：金属质感 `#8a8a8a` → `#c0c0c0` 渐变
- 支架：深灰色 `#4a4a4a`
- 几何图形内部：高亮点缀 `#ff6b9d`（圆形内核）

### 字体
- 标题/提示文字：`"Noto Sans SC", sans-serif`
- 粗细：300（轻盈感）

### 动效哲学
- 弹簧振动使用阻尼谐波振动
- 回弹动画：弹簧系数 k=0.12，阻尼系数 c=0.06
- 拖拽时实时跟随，无延迟

### 组件位置
- 支架：固定在网页底部居中
- 弹簧：从支架中心向上延伸，连接至亚克力图形
- 亚克力图形：位于弹簧顶端，可在 XY 平面自由移动

### 响应式策略
- 摆件居中显示，保持比例
- 移动端触摸操作支持

## 4. 功能与交互

### 核心交互
1. **鼠标拖拽**：点击亚克力图形可在 XY 平面自由拖拽
2. **弹簧拉伸/压缩**：拖拽时弹簧实时伸长或压缩，方向跟随图形位置
3. **释放回弹**：松开后图形以阻尼振动方式回归原位（弹簧正上方）
4. **XY 自由运动**：弹簧和图形在 XY 平面自由运动，物理模拟支持任意方向

### 交互细节
- 拖拽时鼠标变为 `grabbing` 样式
- 拖拽范围限制：最大拉伸距离为初始弹簧长度的 2.5 倍（圆形范围）
- 释放后振动衰减到静止
- 未拖拽时显示轻提示 "拖动图形"

### 边界情况
- 快速连续点击：取消当前动画，执行新拖拽
- 拖到边界外：限制在最大拉伸范围内（圆形限制）
- 窗口 resize：重新计算锚点位置

## 5. 组件清单

### 支架（Bracket）
- 简约扁平矩形，两侧有安装孔装饰，顶部有连接点
- 颜色：深灰渐变
- 固定于页面底部，不参与动画

### 弹簧（Spring）
- 多个螺旋圈，金属质感渐变
- 实时根据图形位置改变长度和角度
- 弹簧沿二次贝塞尔曲线弯曲，垂度随水平位移增大而增大
- 圈数保持恒定，视觉拉伸/压缩效果

### 亚克力图形（Acrylic Shape）
- 默认形状：圆形，带粉色内核点缀与高光点
- 外观：半透明 + 边框 + 内核
- 状态：
  - 默认：静止于弹簧正上方
  - 拖拽中：跟随鼠标，可在 XY 平面自由移动
  - 释放后：阻尼振动回弹至静止位置

### 提示文字（Hint Text）
- 位置：页面居中
- 内容："拖动图形"
- 交互后隐藏

## 6. 技术方案

### 实现方式
- 纯 HTML + CSS + JavaScript（单文件）
- SVG 二次贝塞尔曲线作为弹簧中心线，螺旋圈沿曲线绘制
- CSS 绘制亚克力图形
- requestAnimationFrame 驱动物理动画

### 物理模型（2D 胡克定律）
- 弹簧力：F = -k * (position - restPosition)，restPosition 为锚点正上方 baseLength 处
- 即 Fx = -k * offsetX，Fy = -k * (offsetY + baseLength)
- 阻尼力：F_damp = -c * v
- 弹簧始终趋向复位到垂直方向（x=0）
